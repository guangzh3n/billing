# BillingPro — Malaysia Billing & e-Invoice System

A complete PHP billing system with Malaysia MyInvois (LHDN) e-invoice integration, designed for cPanel shared hosting.

## Features

- **Invoice Management** — Create, edit, print invoices with line items
- **Customer Management** — Full CRUD with TIN and ID fields for MyInvois compliance
- **Product/Service Catalog** — With MyInvois classification codes
- **Payment Tracking** — Record payments (FPX, DuitNow, Bank Transfer, etc.)
- **Malaysia e-Invoice (MyInvois)** — Submit invoices to LHDN, track validation status
- **Reports** — Revenue charts, outstanding invoices, payment methods, top customers
- **PDF/Print** — Browser print-to-PDF with QR code for verified e-invoices
- **Multi-user** — Admin and user roles

## Requirements

- PHP 8.0+
- MySQL 5.7+ / MariaDB 10.3+
- cURL extension (enabled by default on most cPanel hosts)
- mod_rewrite (Apache — enabled on cPanel)

## Installation

1. Upload all files to your cPanel `public_html` (or a subdirectory)
2. Create a MySQL database and user in cPanel → MySQL Databases
3. Navigate to `https://yourdomain.com/install/` in your browser
4. Follow the 3-step wizard (database config → admin account → done)
5. **Delete or rename the `install/` folder** after installation

## cPanel File Permissions

Set via cPanel File Manager:
- Directories: `755`
- Files: `644`
- `logs/` directory: `755` (must be writable)

## Malaysia MyInvois (e-Invoice) Setup

1. Register at [https://myinvois.hasil.gov.my](https://myinvois.hasil.gov.my)
2. Obtain your **Client ID** and **Client Secret** from the MyInvois portal
3. In BillingPro: **Settings → MyInvois e-Invoice**
4. Start with **Sandbox** environment for testing
5. Ensure your **Company TIN** is set in Settings → Company Info

### Required fields for e-Invoice submission:
- Company TIN (Tax Identification Number)
- Company ID Type + Number (BRN for Sdn Bhd)
- Customer TIN (for B2B invoices)
- Customer ID Type + Number

### Digital Signatures (Production)
Sandbox does not require digital signatures. For **production**, LHDN requires signing with a certificate from an approved CA. See `classes/EInvoiceDocument.php` for implementation notes.

## Directory Structure

```
billing/
├── api/                # AJAX endpoints
├── assets/css|js/      # Stylesheets and scripts
├── classes/            # MyInvoisAPI.php, EInvoiceDocument.php
├── config/             # database.php, app.php (generated by installer)
├── includes/           # init.php, auth.php, functions.php, header/footer
├── install/            # Web installer (delete after setup)
├── logs/               # einvoice.log (auto-created)
├── pages/              # All page handlers
├── .htaccess           # URL rewriting
├── index.php           # Front controller
├── login.php           # Login page
└── logout.php          # Logout
```

## Security Notes

- All DB queries use PDO prepared statements (SQL injection safe)
- CSRF tokens on all POST forms
- Session-based authentication with `session_regenerate_id()`
- Sensitive files (`.sql`, `.log`) blocked by `.htaccess`
- Passwords hashed with `password_hash()` (bcrypt)
